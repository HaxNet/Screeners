Screeners — Options

Google Drive

Connect your own Google account. Uploads go only to a Screeners folder in your Drive. The extension uses the narrow drive.file scope — it can only see files it created. Nobody else's Drive is ever involved.

Status: Not connected

Advanced: use your own OAuth Client ID

Optional. If you don't want to rely on the client ID shipped with the extension, create your own (free) in Google Cloud Console and paste it here. See the README for the 5-minute setup.
